# ChatGPT's twists:

## **1. Make the Code Unreadable** ✅

Write a solution using:

* No variable names longer than 1 character
* Excessive nesting
* Ternaries inside ternaries
* Obscure JS features (comma operator, bitwise tricks, etc.)

---

## **2. Use a Generator Function** ✅

Solve the problem by creating a generator that yields intermediate steps or partial results before producing the final answer.

---

## **3. Only Use Recursion** ✅

No loops allowed:

* No `for`, `while`, `forEach`, etc.
* Everything must be done with recursive calls.

---

## **4. Solve It Using Functional Programming Only** ✅

Your constraints:

* No mutation
* No `let` or `var`
* Only pure functions, recursion, `map`, `reduce`, `filter`, etc.

---

## **5. Use a Proxy to Intercept Operations** ✅

Your solution must:

* Wrap some object or function with a `Proxy`
* Use traps (`get`, `set`, or `apply`) to enforce logic or constraints
* Make the Proxy contribute meaningfully to the algorithm

---

## **6. Solve It With Only Regular Expressions**

You must implement as much of the solution as possible using:

* `.match()`
* `.replace()`
* Lookaheads/lookbehinds
  Basically: regex-as-a-hammer even when it shouldn't be.

---

## **7. Use Bitwise Operations for Everything**

Even simple arithmetic and checks should use:

* `^`, `&`, `|`, `>>`, `<<`, `~`
* Convert logic into bit manipulation when possible

---

## **8. Write the Solution as a Single Expression**

No multiple statements:

* One giant expression
* Likely involving IIFEs, logical operators, ternaries, or reduce chains
* Semicolons forbidden

---

## **9. Hack It With Memoization or Dynamic Programming**

Force yourself to:

* Build a reusable memoization function
* Optimize a brute-force version into a DP table or memoized recursion
* Show both versions

---

## **10. Treat the Input as a Stream**

You must:

* Pretend input comes in chunks
* Process incrementally
* Accumulate or update state lazily
  Great for string, array, or parsing problems.

---

## **11. Use Object-Oriented Programming With Classes**

Solve the problem by:

* Creating a class with methods
* Maybe make it look like a tiny library
* Create an instance to run the algorithm

---

## **12. Solve It Using Weird or Forbidden JS Features**

You must use at least two of:

* `with` (evil)
* `eval()` (double evil)
* `Function()` constructor
* Implicit global variables
* `arguments.callee`

Basically: stuff nobody should use in production.
